HashiCorp Vault установлен!

Namespace: {{ .Release.Namespace }}
Режим: standalone с persistent volume

=== Доступ к Vault ===

Web UI: https://vault.tataredu.test
  Метод: Token
  Token: используйте локальный root token только для администрирования

API: https://vault.tataredu.test/v1/

=== Переменные для CLI ===

export VAULT_ADDR=https://vault.tataredu.test
export VAULT_SKIP_VERIFY=true   # самоподписанный сертификат

=== Настройка секретов (см. helm/scripts/vault-setup.sh) ===

VAULT_TOKEN=<root-token> bash helm/scripts/vault-setup.sh

=== ВНИМАНИЕ ===
После перезапуска pod Vault остаётся sealed. Выполните:
  bash helm/scripts/vault-init.sh

Ключи unseal и root token находятся только в игнорируемом локальном файле.
Текущая standalone-конфигурация подходит для учебного Minikube, но не обеспечивает HA.
